# Интеграция Умной Шторы ESP32 с Алисой (Яндекс Dialogs) через MQTT

Этот проект обеспечивает интеграцию умной рулонной шторы на базе ESP32 (прошивка ESPHome, шаговый мотор через драйвер ULN2003) с системой домашней автоматизации **Яндекс Алиса** через MQTT-брокер.

## Архитектура
```
[ Яндекс Алиса ]  <-- (HTTPS / REST API) -->  [ FastAPI шлюз (сервер) ] 
                                                      ^
                                                      | (MQTT)
                                                      v
                                              [ MQTT Брокер ]
                                                      ^
                                                      | (MQTT)
                                                      v
                                             [ ESP32 (Штора) ]
```

## Что было улучшено в проекте:
1. **Нативная поддержка шторы в Алисе**:
   - Ранее устройство регистрировалось как обычный переключатель (`devices.types.switch`), из-за чего в приложении Яндекса оно отображалось в виде лампочки или кнопки розетки.
   - Теперь используется нативный тип `"devices.types.opening"` (устройство открытия). Алиса автоматически отобразит его в виде штор/жалюзи на главном экране и правильно свяжет голосовые команды *"Алиса, открой штору"* и *"Алиса, закрой штору"* с булевыми значениями (`True` = `OPEN` / `False` = `CLOSE`).
2. **Динамическая синхронизация состояния шторы**:
   - Раньше приложение шлюза хранило статус шторы исключительно в памяти и не знало, если штора была открыта/закрыта физически или через другие интерфейсы.
   - Теперь шлюз подписывается на MQTT-топик состояния шторы (`shpora_curtain/cover/curtain/state`) и автоматически синхронизирует глобальный статус (`CURTAIN_STATE`). При опросе Алисой шлюз отдает реальное актуальное положение шторы.
3. **Безопасность (Авторизация)**:
   - Внедрена обязательная проверка `Bearer` токена для всех запросов управления и получения данных от Яндекса (`/v1.0/user/...`). Это предотвратит несанкционированный доступ из интернета.
4. **Resilience (Отказоустойчивость)**:
   - Подключение к MQTT-брокеру теперь происходит асинхронно через метод `connect_async`. Если ваш MQTT-брокер временно недоступен во время запуска шлюза, сервер FastAPI запустится успешно и будет автоматически пытаться подключиться в фоновом режиме.
5. **Безопасное хранение секретов в ESPHome**:
   - Настройки Wi-Fi и MQTT вынесены в `secrets.yaml`. Вы можете безопасно публиковать основной конфигурационный файл `esphome_configuration.yaml` без компрометации паролей.
6. **Докеризация**:
   - Проект полностью подготовлен для развертывания в Docker и Docker Compose с использованием быстрой утилиты управления зависимостями `uv`.

## 🚀 Как запустить gateway в Docker

### Шаг 1: Подготовка конфигурации
В корне проекта находится шаблон `.env.example`. Скопируйте его под именем `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и настройте параметры подключения к вашему MQTT брокеру и секретный токен для Алисы.

### Шаг 2: Генерация файла паролей MQTT брокера
Поскольку файл паролей `mosquitto/config/passwd` содержит конфиденциальные хешированные данные и добавлен в `.gitignore`, перед первым запуском брокера его необходимо сгенерировать локально на основе настроек из вашего `.env`.

Для этого запустите Python-скрипт в корне проекта:
```bash
python3 generate_passwd.py
```
Скрипт автоматически считает `MQTT_USER` и `MQTT_PASS` из `.env` и создаст зашифрованный файл по пути `mosquitto/config/passwd`.

### Шаг 3: Запуск с использованием Docker Compose
Чтобы собрать и запустить контейнер в фоновом режиме, выполните:
```bash
docker compose up -d --build
```
Шлюз запустится и будет слушать порт `8000` на вашем сервере/мини-ПК.

*(В файле `docker-compose.yml` также закомментирована конфигурация для локального MQTT брокера Eclipse Mosquitto. Если у вас еще нет MQTT брокера, вы можете раскомментировать этот блок и запустить его в одном окружении).*

## 🛠️ Настройка ESPHome

1. Скопируйте пример файла секретов:
   ```bash
   cp secrets.yaml.example secrets.yaml
   ```
2. Укажите ваши данные Wi-Fi сети и IP-адрес/логин/пароль MQTT-брокера внутри `secrets.yaml`.
3. Скомпилируйте и прошейте плату ESP32 с использованием настроенного `esphome_configuration.yaml`.

## ☁️ Настройка интеграции в консоли Яндекса

1. Перейдите в [Консоль разработчика Яндекс Диалогов](https://dialogs.yandex.ru/developer).
2. Создайте новый диалог с типом **Умный дом**.
3. Настройте следующие параметры:
   - **Endpoint URL**: `https://<DOMAIN_OF_YOUR_GATEWAY>/v1.0` (шлюз должен быть доступен извне по https, можно использовать Nginx Reverse Proxy, Cloudflare Tunnel, Ngrok и др.).
   - Настройка OAuth протокола:
     - **Авторизационный URL**: `https://<DOMAIN_OF_YOUR_GATEWAY>/auth`
     - **URL для получения токена**: `https://<DOMAIN_OF_YOUR_GATEWAY>/token`
     - **Client ID** и **Client Secret**: Любые значения (так как наш шлюз использует упрощенную fake-авторизацию).
4. В качестве токена доступа, пропишите значение переменной `YANDEX_TOKEN` из вашего файла `.env` (по умолчанию `super_secret_master_token_2026`).
5. Нажмите кнопку **Тестировать** и свяжите аккаунт в мобильном приложении "Дом с Алисой". Устройство "Штора" появится в вашем списке устройств умного дома.
